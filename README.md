# 🎓 빌려드립니다

### 동양미래대학교 한울타리 총학생회 물품 대여 관리 시스템

**빌려드립니다**는 동양미래대학교 총학생회에서 운영하는 물품 대여 서비스를 디지털화한 웹 애플리케이션입니다.

기존의 Google Forms와 스프레드시트 중심 수기 관리 방식을 개선하여 학생의 대여 신청부터 관리자의 승인, 물품 반납, 재고 관리 및 이용 통계까지 하나의 시스템에서 처리할 수 있도록 개발했습니다.

## 01. 프로젝트 개요

| 항목 | 내용 |
|---|---|
| 프로젝트명 | 빌려드립니다 |
| 프로젝트 유형 | 백엔드실무프로젝트 |
| 개발 형태 | 2인 팀 프로젝트 |
| 서비스 대상 | 동양미래대학교 재학생 및 총학생회 임원 |

### 개발 배경

기존 총학생회 물품 대여 서비스는 Google Forms를 통해 신청을 접수하고, 스프레드시트에 대여 및 반납 내역을 수기로 기록하는 방식으로 운영되었습니다.

이러한 방식은 물품의 실시간 대여 가능 여부를 확인하기 어렵고, 담당자의 수작업에 의존하기 때문에 관리 효율성이 떨어진다는 문제가 있었습니다.

이를 해결하기 위해 학생과 관리자 모두 편리하게 사용할 수 있는 통합 물품 대여 관리 시스템을 개발했습니다.

### 개발 목표

- 학생의 물품 대여 신청 절차 간소화
- 실시간 물품 재고 및 대여 현황 제공
- 대여 승인 및 반납 처리 자동화
- 연체 횟수 누적 및 이용 제한 관리
- Google Sheets 당직표 연동
- 대여 기록 기반 이용 통계 제공

## 03. 시스템 구성

본 서비스는 학생용 모바일 웹과 관리자용 웹으로 구분됩니다.

학생은 별도의 로그인 없이 물품을 조회하고 대여를 신청할 수 있으며, 관리자는 로그인 후 신청 승인과 반납, 재고 및 운영 정책을 관리합니다.

### 시스템 구조

```text
[학생 모바일 웹]
       │
       ├── 물품 현황 조회
       ├── 대여 신청
       ├── 이용 안내
       └── 당직자 전화 연결
       │
       ▼
[Spring Boot Server]
       │
       ├── REST API
       ├── Spring Security
       ├── 대여 및 반납 처리
       ├── 재고 관리
       ├── 이용 제한 관리
       └── 통계 데이터 처리
       │
       ├──────────────┐
       ▼              ▼
[H2 Database]   [Google Sheets]
       ▲              │
       │              │
[관리자 웹]      [당직표 조회]
       │
       ├── 신청 관리
       ├── 대여 승인
       ├── 반납 처리
       ├── 물품 관리
       ├── 운영 설정
       └── 이용 통계
```

## 08. 실행 방법

### 8.1 실행 환경

프로젝트 실행을 위해 다음 환경이 필요합니다.

- JDK 17
- IntelliJ IDEA
- Gradle Wrapper
- 인터넷 연결(최초 의존성 다운로드 시)

### 8.2 프로젝트 실행

**① 프로젝트 열기**

IntelliJ IDEA에서 `settings.gradle`이 있는 `campus-loan` 폴더를 엽니다.

**② JDK 설정**

Project SDK와 Gradle JVM을 JDK 17로 설정합니다.

**③ 애플리케이션 실행**

`CampusApplication.java`의 `main()` 메서드를 실행합니다.

또는 Windows PowerShell에서 다음 명령어를 실행합니다.

```powershell
.\gradlew.bat bootRun
```

**④ 웹페이지 접속**

학생용 웹페이지:

```text
http://localhost:8080/
```

관리자 웹페이지:

```text
http://localhost:8080/admin
```

관리자 인증 정보는 실행 환경에 설정된 계정을 사용합니다.

> 실제 운영 또는 외부 공개 전에는 기본 관리자 비밀번호를 반드시 변경해야 합니다.

### 8.3 환경변수

| 환경변수 | 설명 |
|---|---|
| `ADMIN_PASSWORD` | 관리자 초기 비밀번호 |
| `SHEETS_ID` | Google Sheets 문서 ID |
| `GOOGLE_APPLICATION_CREDENTIALS` | Google 서비스 계정 인증 파일 경로 |

서비스 계정 인증 파일과 실제 비밀번호는 GitHub에 업로드하지 않습니다.

## 10. 휴대폰 접속 방법

본 프로젝트는 로컬 네트워크 환경에서 학생 모바일 웹과 관리자 PC를 함께 사용할 수 있도록 구성했습니다.

**① 서버 실행**

노트북에서 Spring Boot 애플리케이션을 실행합니다.

**② IP 주소 확인**

Windows PowerShell에서 다음 명령어를 입력합니다.

```powershell
ipconfig
```

현재 연결된 Wi-Fi의 IPv4 주소를 확인합니다.

**③ 동일 네트워크 연결**

학생 휴대전화와 서버 노트북을 동일한 Wi-Fi에 연결합니다.

**④ 모바일 접속**

노트북의 IP 주소가 `192.168.0.10`인 경우:

```text
http://192.168.0.10:8080/
```

실제 접속 시에는 확인한 IPv4 주소로 변경해야 합니다.

Windows 방화벽 설정 또는 학교 네트워크의 기기 간 통신 제한에 따라 접속이 차단될 수 있습니다.

## 11. Google Sheets 당직표 연동

총학생회에서 기존에 사용하던 Google Sheets 당직표를 활용합니다.

### 연동 방식

1. 현재 날짜 확인
2. 날짜에 해당하는 월별 시트 조회
3. 해당 날짜의 당직자 2명 확인
4. 등록된 임원 정보와 대조
5. 학생용 전화 연결 기능에 반영

공개 열람이 가능한 시트는 별도 API 키 없이 조회할 수 있습니다.

비공개 시트는 Google Sheets API와 서비스 계정 인증을 통해 읽기 전용으로 연동할 수 있습니다.

당직표에는 전화번호가 포함되어 있지 않으므로, 관리자 화면에서 임원별 연락처를 별도로 등록해야 합니다.
